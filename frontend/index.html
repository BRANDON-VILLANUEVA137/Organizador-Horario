Cómo sincronizar tu historia académica

  1. Haz clic en "Abrir portal UDEC" para abrir Academusoft
  2. Inicia sesión con tus credenciales Microsoft/UDEC
  3. Navega a: Académico Estudiante → Calificaciones → Registro Extendido
  4. Guarda el reporte como PDF (Ctrl+P → Guardar como PDF) o copia el texto (Ctrl+A, Ctrl+C)
  5. Arrastra el PDF o pega el texto en las opciones de abajo
